# Trading Bot (WIP)

## Install Dependencies
  ```
  $ pip install -r requirements.txt
  ```
## Description
Trade algorithm assigns buy and sell points and will provide profit results.

## How to use
Modify the tickers array to change what data is visualised.

  ```
  tickers = ["ABBN.SW", "ADM.L", "AV.L", "BATS.L"]
  ```
